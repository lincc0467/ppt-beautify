## 字型鏈

```
無襯線  "Noto Sans TC","Microsoft JhengHei",sans-serif
襯線    "Noto Serif TC","PMingLiU",serif
等寬    "Consolas","Menlo","Noto Sans TC","Microsoft JhengHei",monospace
```

**一律 TC 不用 SC。** 用了 SC，繁體字會落到簡體字形，一眼看得出來。
`PingFang SC` 也不行，要寫 `PingFang TC`。

PPTX 匯出時只保留字型鏈的**第一個名稱**，所以等寬字用系統內建款——
用 webfont 在沒裝該字型的機器上會 fallback 破版。

## 排版慣例

- **中文不用斜體。** 中文字形沒有真正的義大利體，斜體是機械傾斜，很醜
- 引號用「」與『』，不用 `""`
- 中英數之間留半形空格（`Noto Sans TC` 會自動處理一部分，但文案裡手動留更穩）
- 破折號用 `——`（兩個全形），不用 `--`
- 數字一律半形，並在 CSS 用 `font-variant-numeric: tabular-nums` 讓位數對齊
- 條列句盡量壓成一行，避免換行破碎；長句改拆成 `k` / `v` 兩欄

## 常見殘留

改版後掃一次這些字，通常是簡繁轉換工具漏掉的：
`仅`（僅）、`叙`（敘）、`别`（別）、`产`（產）、`发`（發）、`会`（會）、`应`（應）、`实`（實）

```bash
grep -nP '[\x{4e00}-\x{9fff}]' content.js | grep -P '仅|叙|别|产|发|会|应|实|个|们|来|时'
```
